# ARDS data files

`ards.db` in the GitHub repository is a public distribution snapshot containing
only the 600 released challenge statements. It omits unreleased selections,
teacher PPCs, reference solutions, hidden tests, learner attempts, and exposure
records. It is suitable for browsing the released problem library; it is not a
backup of the local canonical learner archive.

The active local `data/ards.db` remains ignored by Git and is the source of truth
for authoring, review, learner records, and future releases. Never replace it
with the tracked public snapshot. The local workspace was reset on
2026-10-20T22:55:25Z at the learner's request, with no new backup; older external
backups were not altered or imported.
